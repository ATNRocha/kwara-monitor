# Portfolio notes

Kwara Monitor is a personal engineering project created to centralize auction monitoring, financial calculations and lot prioritization.

The project demonstrates:

- Python automation with Playwright and Chromium
- SQLite persistence and historical snapshots
- adaptive polling
- real-time browser UI without full-page reloads
- Linux/systemd operations and service resource limits
- OCI ARM64 deployment
- private publication through Cloudflare Tunnel + Access
- controlled reboot / automatic recovery validation

> Independent personal project. It is not affiliated with, endorsed by, or operated by the auction platform whose public pages are monitored.
